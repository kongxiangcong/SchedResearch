# Implementation clarifications (before first timing)

This supplements, and does not replace, the frozen plan/contract. No performance data had been produced at this clarification.

* Blackouts pause all charged port service, including descriptor/setup and payload. A command occupies its port during a blackout; completion is its sole visibility event. Compute is unaffected. This selects the explicit "also charged service" reading in contract.json.
* Baseline and resident have independent train rankings and independent top-three validation; each candidate's depth is shared between its projection ping-pong budget and recurrence lookahead budget. Both get the identical choices. Illegal RF combinations (e.g. two complete head states plus operands >128 KiB) are excluded before timing. Head-major baseline means h,t,value-tile; token-major means t,h,value-tile. Resident means h,value-tile,t. No arithmetic reduction order changes with value tiling.
* Timing uses compile-time FIFO orders per resource. Dependencies and resource edges are evaluated to reconstruct every queue; no observed phase changes compiler order. Projection processes a two-core output-tile wave with K ascending, overlap within the wave, then next wave. Recurrence can prefetch one independent job pair into a second slot; if it depends on the current state write, prefetch occurs after that write. This is ordinary legal static prefetch, not a new runtime selector.
* Small conv/gate/norm parameters use FP32 in EXT and VMEM. Dense weights use the packed BF16 contract; RF consumes expanded FP32, with VPU unpack commands. Full raw qkv, z, a/b, prepared vectors, all recurrence outputs, normalized outputs and final module outputs are reserved in VMEM. Fixed address allocation is conservatively reserved through the entire invocation, so there is no hidden buffer reuse. State uses its full 2 MiB VMEM region; two per-core projection slots have explicit overwrite dependencies. All allocated bytes count even when temporarily unused.
* Prepared and normalized input output vectors are explicitly transferred for every consuming compute phase. Conv/preparation streams channel/head groups through private scratch; its grouped operation/traffic accounting is an abstract reference kernel, with a conservative 64 KiB scratch reservation and complete formula ledger. It is not a claim of calibrated SFU implementation.
* Deterministic projection/pointwise phase graphs may be cached across static candidates only for identical absolute start, depth, inputs-shape and exogenous phase. The full test trace still includes all commands and the independent auditor replays all of them. Performance is independent of synthetic numerical values; source shapes and fixed work are shared.
