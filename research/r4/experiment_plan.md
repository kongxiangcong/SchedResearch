# R4 pre-experiment contract

Written before the main test sweep on 2026-09-05. The task is to find residual opportunity, not to establish that OoO helps. R3 is frozen in `r3_snapshot/`; public `sim/` is unchanged.

Four source-transcribed, random-weight scaled cases: Qwen3.5 full-attention cached decode block, Qwen3.5 GatedDeltaNet cached decode block, FLUX.2 klein distilled double-stream and single-stream blocks. The exact model/source revisions are in model evidence and machine manifests. These are not full-width 4B execution or production compiler outputs. At least one numerical output AND persistent state must match an independent direct formula after fusion and reordered execution.

Source fusion includes packed QKV/gate-up, head/intermediate/query-row partitioning and same-core single-consumer VPU chains. Operand DMA packs use compiler-owned ping-pong buffers (two/core), explicit last-reader WAR, legal partial-order activation reuse, and pinned live-outs. Both policies receive the same physical plan. No K-split full-width GEMM, full FlashAttention implementation or exhaustive fusion/mapping optimum is claimed.

Main target is one cluster, two fixed cores, each with one MXU and VPU; one shared DMA/outstanding transfer; two statically mapped shared SRAM ports. Aggregate compute 1024 MAC/cycle/core, VPU 32 estimated primitive ops/cycle, DMA 32 B/cycle, SRAM 64 B/cycle/port, SRAM 4 MiB, 32x32 tile anchor. These are research assumptions loosely anchored in R1, NOT a real BF16 NPU specification. Analytical compute service uses max(MAC/throughput,bytes/SRAM bandwidth)+1; it does not model array fill or actual bank/beat accesses. All resources are held over whole tasks. Storage uses BF16 data and explicitly marked FP32 recurrent/selected parameters; float64 numeric checks do not validate those roundings.

Uncertainty groups: deterministic, task-identity bounded external DMA service multiplier U[0.5,1.5], absolute-time periodic background availability (period256 cycles, half at 0.25 rate, common seeded phase), combined. Compute is deterministic. Calendar affects the same external environment under all policies; changed execution times are re-integrated, not copied from another policy's queueing trace. The calendar is a hypothesis, not LPDDR calibration. It also scales modeled DMA startup; this is a coarse service-availability assumption.

Static S8 chooses a fixed plan from the inherited eight-priority pool using training only. Stronger S expands to24 priorities plus128 legal insertion/swap candidates; each candidate preserves mapping, addresses, reuse edges. Train seeds10000..10011; validation20000..20007 selects from training finalists and pool incumbents; held-out test0..31. B uses the selected S compiler priority and ignores resource order only after completion readiness. H keeps compute-engine orders but readiness-arbitrates DMA/SRAM; it is an existing-style resource-aware baseline, not fully dynamic. B0 has the same common costs as S; B2 and B8 add2/8 cycles dispatch latency/task. Common issue1/cycle, dispatch1, completion1, wakeup1/cycle, 128 entries/32KiB descriptors. Resource reservation includes dispatch setup, a conservative modeling choice.

Main sweep is four cases x four uncertainty modes. Sensitivities use external service uncertainty and independently rerun static training: DMA16/64 B/cycle; shared SRAM one port; operand slots1/4; SRAM2/8MiB. Fixed shape work remains the same, while slot/capacity/fusion comparisons disclose traffic/memory/control changes. All policies within a configuration share work, addresses, environment and capacity. No across-chip sweep until a local opportunity survives.

Report paired latency reduction mean(100*(S-X)/S), 95% normal sampling interval, means/p95, engine occupancy, exclusive task wait (not wall stall), union of times with legal alternative and all needed resources/issue lane free, dependency-ready order inversions, queue peaks, descriptor/state estimates, issue/wakeup service rates. Save all seeds' traces. For seed0 apply up to6 one-action bypass counterfactuals to S using the identical environment; label these offline causal probes, not an online oracle. A reduced source-tile dependency graph will enumerate all static orders and per-environment clairvoyant optimum, with exactness limited to that graph.

Keep the R3 pre-registered screening gate: charged B2 must improve at least5% with paired interval above0 in a representative case before finite-total-event-state is prioritized. Deterministic wins or static search budget exhaustion do not prove unpredictable completion information. Source scaling and uncalibrated service remain independent limitations even if the synthetic gate passes. Negative results and regressions are retained. Independent redteam checks timing, memory, source/numeric scope, test isolation and artifacts; none constitute RTL/PPA or silicon acceptance.
