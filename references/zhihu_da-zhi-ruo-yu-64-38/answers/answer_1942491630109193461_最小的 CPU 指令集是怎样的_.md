# 最小的 CPU 指令集是怎样的？

- 类型：回答
- 问题：最小的 CPU 指令集是怎样的？
- 原文：[知乎回答](https://www.zhihu.com/question/36187949/answer/1942491630109193461)

这一点上，RISCV-G profile是做的最好的。二十多条指令就可以跑起来复杂的软件系统。

那怎么跑起来复杂的软件生态呢？

只需要让这个最小的RISCV核跑起来wasm (web assembly)虚拟机即可。

WASM虚拟机对接了海量的软件接口。各种系统操作，浮点操作，都可以通过软件模拟。

- 部分通过以存带算，查表即可
- 部分通过牛顿拟合，泰勒展开
- 实在搞不定的，就发一个消息给其他CPU搞定。

当然，指令集上想进一步简化还是有空间的，riscv的指令编码还可以进一步压缩。做成stack machine, 这样连寄存器都省了。
