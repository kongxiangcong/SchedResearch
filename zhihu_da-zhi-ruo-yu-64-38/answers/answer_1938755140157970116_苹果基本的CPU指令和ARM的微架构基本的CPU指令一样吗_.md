# 苹果基本的CPU指令和ARM的微架构基本的CPU指令一样吗？

- 类型：回答
- 问题：苹果基本的CPU指令和ARM的微架构基本的CPU指令一样吗？
- 原文：[知乎回答](https://www.zhihu.com/question/1936034527416922654/answer/1938755140157970116)

在基本的ARM扩展下，苹果加了很多私货指令扩展进去。

具体加了哪些指令和系统寄存器，有github反向工程

[https://github.com/lelegard/arm-cpusysregs/blob/main/docs%2Fapple-m1-features.md](https://link.zhihu.com/?target=https%3A//github.com/lelegard/arm-cpusysregs/blob/main/docs%252Fapple-m1-features.md)

理论上，苹果完全可以设置一条手册没有定义的系统寄存器，然后设置完这个隐藏的寄存器后，把一条ARM的指令的执行语义完全修改掉。

至少ARM指令集里面，条件跳转指令有1bit被用来reserve了，编码空间不给宝贵的跳转偏移，反而给了1bit hint。堂而皇之称为hinted branch。非常可疑。

有人也做过x86的指令集后门研究: [https://youtu.be/KrksBdWcZgQ?si=rRXTlY5AyUZvsruh](https://link.zhihu.com/?target=https%3A//youtu.be/KrksBdWcZgQ%3Fsi%3DrRXTlY5AyUZvsruh)

至少苹果作为ARM第一大客户, ARM也不敢说啥，任凭苹果蹂躏ARM。

直到某一天在剑桥举办的APM上，苹果的扩展可能会推回ARM, 才能让其他的友商喝点汤。
