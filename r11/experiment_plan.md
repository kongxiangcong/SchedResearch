# R11 preregistration — full GDN static residency

Registered before any R11 performance execution, 2026-09-05. The frozen R5/R6 source, source_independent_review and handoff define the motivation. No dynamic scheduler, new storage, partitioning experiment, target SDK or R10 follow-up is in scope.

## Research Question → Hypothesis

Can the R5 local-state traffic reduction retain at least **5% net full GDN module elapsed improvement** with all 32 value heads and legal input release? H-P: a known four-token continuation/prefill block permits head-major four-step retention. H-D: strict autoregressive invocation boundaries may remove the same reuse. “Full GDN” means Qwen3_5GatedDeltaNet.forward, including qkv/z/a/b projection, causal convolution, gate and qk preparation, recurrence, gated RMSNorm and out projection; excludes surrounding decoder RMSNorm/residual/FFN and the other layers. No full decoder/model throughput claim.

## Strong Baseline and candidate

Both use the same staged module ABI, shapes, arithmetic, two cores, tiles, prefetch budget, resources and EXT initial/final locations. Projection and recurrence phases have explicit library barriers; cross-operator fusion is outside this candidate. The strengthened baseline releases every state tile to VMEM after each token; the candidate retains it across all legally available tokens. Independent finite compiler budgets: value tiles 32/64/128, head-major or token-major baseline order, prefetch depth 1/2; candidate value tiles 32/64/128 and depth 1/2 (head-major is required for reuse). Every order is static. Shared projection lowering uses K=128, N=64 ping-pong, reuses each weight tile across four prefill tokens, overlaps DMA/feed/compute, ascending K accumulation; depth 1/2 is available to both. Select using mean train elapsed across quiet/background, top three validation, minimum validation mean with lexicographic ties. Freeze selection before test. Selection strength is bounded by these stated stage/tiling constraints, not a proof of global compiler optimality.
